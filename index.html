Cloud Services Assignment

Deployment of a web application using CSC Rahti and media storage using CSC Allas.

1. Cloud-Based Email and Calendar Services

Many companies use cloud-based email and calendar services because they reduce the need to maintain their own messaging infrastructure. Instead of operating mail servers, storage systems and backup infrastructure themselves, companies can use services provided by large cloud providers.

A major advantage is scalability. Cloud services can support both small organizations and large enterprises without requiring the company to purchase additional physical hardware.

Cloud services also provide accessibility. Employees can access email and calendars from different locations and devices using an Internet connection. This is particularly useful for remote and hybrid work.

Another benefit is reduced maintenance. The cloud provider is responsible for much of the server maintenance, software updates, infrastructure availability and security.

2. Amazon Glacier

A mid-size company could use Amazon S3 Glacier storage classes for data that needs to be retained for a long time but is rarely accessed.

Examples include old backups, historical business documents, financial records, archived emails, application logs and older media files.

Glacier should generally not be used for data that needs to be accessed frequently or immediately, such as active databases, frequently used website files or current application data.

The main advantage of archive storage is the lower storage cost. The trade-off is that retrieving archived data can take longer and may involve additional retrieval costs.

Other cloud storage providers

  • Amazon Web Services – Amazon S3
  • Microsoft Azure – Blob Storage
  • Google Cloud – Cloud Storage
  • Backblaze – B2 Cloud Storage

3. Comparison of Cloud Storage Providers

Provider Service Main Characteristics
AWS Amazon S3 Scalable object storage with different storage classes for frequently and rarely accessed data.
Microsoft Azure Blob Storage Hot, Cool, Cold and Archive tiers for different access patterns.
Google Cloud Cloud Storage Multiple storage classes including Standard, Nearline, Coldline and Archive.
Backblaze B2 Cloud Storage Object storage focused on backup and general cloud storage use cases.

The most suitable provider depends on storage capacity, access frequency, geographical requirements, retrieval needs, data transfer costs and integration with other cloud services.

4. Own Web Server vs IaaS, PaaS and SaaS

Maintaining an own physical web server can be appropriate when an organization requires full control over its hardware, network environment or data location. It can also be useful when an organization already has suitable infrastructure and technical expertise.

However, maintaining physical infrastructure requires responsibility for hardware failures, operating system updates, security, backups, networking, electricity and system administration.

IaaS provides virtual machines while the cloud provider manages the underlying physical infrastructure. The customer is still responsible for the operating system and applications.

PaaS provides a higher level of abstraction. Developers can deploy applications without managing most of the underlying infrastructure. This can make development and deployment faster.

SaaS provides a complete software application managed by the provider. It is commonly used for services such as email, collaboration and customer relationship management.

The choice depends on the required level of control, responsibility, flexibility, cost, scalability and technical expertise.

Implementation

This web application was deployed using CSC Rahti as the PaaS platform. The source code is stored in GitHub.

Media files used by the webpage are stored separately in CSC Allas, which provides S3-compatible object storage.

Deployment process

  1. The source code was stored in a GitHub repository.
  2. The web application was deployed to CSC Rahti.
  3. Media files were uploaded to CSC Allas.
  4. The webpage was configured to access the media from Allas.
  5. The final application was tested through its public URL.
